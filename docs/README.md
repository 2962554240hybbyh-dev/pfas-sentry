# 基于 QSAR-GNN 与 RAG 的全氟化合物（PFAS）毒性预测与风险评估一体化系统

## 项目概述
全国环境友好科技竞赛 — AI+环境与前沿技术赛道

## 系统架构
```
┌─────────────────────────────────────────────────────┐
│  上层：RAG 增强的风险评估与辅助决策系统（20%）          │
│  · 毒性预测查询  · 毒性机制解释  · 风险评估报告       │
├─────────────────────────────────────────────────────┤
│  中层：多源异构知识库（20%）                           │
│  · 文献知识图谱  · 法规标准库  · 向量知识库            │
├─────────────────────────────────────────────────────┤
│  底层：GNN+QSAR 双模型预测引擎（60%）                 │
│  · 数据整合  · QSAR模型  · GNN模型  · 模型融合       │
└─────────────────────────────────────────────────────┘
```

## 目录结构
- `01_数据采集与预处理/` — 多源PFAS数据采集、清洗、特征工程
- `02_QSAR模型/` — 6种传统ML模型构建与解释
- `03_GNN模型/` — 5种GNN模型构建与解释
- `04_模型融合与预测/` — 集成模型与新兴PFAS预测
- `05_知识图谱/` — PFAS知识图谱构建
- `06_RAG系统/` — RAG增强风险评估系统
- `07_可视化与报告/` — 图表、架构图、报告输出
- `scripts/` — 所有Python脚本
- `data/` — 原始数据、清洗数据、特征数据
- `models/` — 训练好的模型文件
- `outputs/` — 预测结果、图表、报告
- `docs/` — 文献PDF、法规文本

## 技术栈
- **化学信息学**: RDKit, PaDEL-Descriptor
- **机器学习**: scikit-learn, XGBoost, LightGBM
- **深度学习**: PyTorch, PyTorch Geometric
- **模型解释**: SHAP, LIME, GNNExplainer
- **知识图谱**: Neo4j, NetworkX
- **向量数据库**: FAISS
- **RAG系统**: LangChain
- **可视化**: Matplotlib, Seaborn, Mermaid
