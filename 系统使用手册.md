# PFAS-Sentry User Manual

## 1. Toxicity Prediction

### How to use
1. Go to **Prediction** page
2. Select a compound from dropdown or enter SMILES
3. Click **Predict**

### Output
- **Compound info**: name, CAS, formula, MW, category
- **Molecular structure**: 2D structure image
- **Bar chart**: 6 endpoint predictions with color coding
- **Radar chart**: endpoint distribution
- **Pie chart**: risk distribution
- **Table**: detailed predictions with 95% CI

### Endpoints
| Endpoint | Full Name |
|----------|-----------|
| NR-AR | Androgen Receptor Antagonism |
| NR-AR-LBD | Ligand Binding Domain Activity |
| NR-AhR | Aryl Hydrocarbon Receptor |
| SR-HSE | Heat Shock Element Response |
| SR-MMP | Mitochondrial Membrane Potential |
| SR-p53 | p53 Pathway Activation |

### Risk Levels
- **High** (>0.6): Red
- **Medium** (0.3-0.6): Orange
- **Low** (<0.3): Green

## 2. RAG Q&A

### How to use
1. Go to **Q&A** page
2. Click a preset question or type your own
3. Click **Ask**

### Sample questions
- Why is PFOA toxic?
- What are the health effects of PFAS?
- How to remove PFAS from drinking water?
- Is GenX safer than PFOA?
- What are the regulatory standards?

### Features
- All answers cite PubMed sources
- Confidence score shown
- PMID verifiable at pubmed.ncbi.nlm.nih.gov

## 3. Comparison Analysis

### How to use

## 5. Model Information

### Three-stage prediction
1. **Pre-training**: Tox21 dataset (7,831 compounds)
2. **Fine-tuning**: PFAS-specific data (20 compounds)
3. **Calibration**: PubMed literature (28-61 papers per endpoint)

### Model performance (AUC)
| Endpoint | Best Model | AUC |
|----------|------------|-----|
| NR-AR | LightGBM | 0.795 |
| NR-AR-LBD | Stacking | 0.874 |
| NR-AhR | XGBoost | 0.906 |
| SR-HSE | XGBoost | 0.834 |
| SR-MMP | XGBoost | 0.923 |
| SR-p53 | RF | 0.879 |

## 6. FAQ

**Q: Why are predictions different from literature?**
A: Predictions are based on Tox21 data. For calibrated compounds (PFOA, PFOS), predictions align with literature (>90% consistency).

**Q: Can I use this for non-PFAS compounds?**
A: The model is optimized for PFAS. For non-PFAS, predictions are less reliable.

**Q: How to verify the data sources?**
A: All papers have PMIDs. Visit https://pubmed.ncbi.nlm.nih.gov/{PMID} to verify.

**Q: Can I download the report?**
A: Yes, click "Generate Report" on the Prediction page to get a Markdown report.
